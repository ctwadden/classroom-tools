## Cross-domain design skills
Photoshop projects also reference the **GD-*** skills in `domains/design/DESIGN_FOUNDATIONS_SKILLS.md`. This separates **software operation** (for example, PS-TYP-01) from **design reasoning** (for example, GD-TYP-01).

## Rule for projects
A project manifest identifies:
- `prerequisites`: skills already taught; link to refreshers rather than reteaching them.
- `new`: skills the project teaches explicitly.
- `reinforced`: previously taught skills used again.
- `transfer`: skills students must apply in a changed or independent context.

Tutorial completion is practice. Competency is confirmed from repeated, teacher-verified evidence.
