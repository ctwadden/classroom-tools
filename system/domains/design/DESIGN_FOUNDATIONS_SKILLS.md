# DESIGN FOUNDATIONS SKILLS — Cross-Software Registry

These skills are intentionally software-independent. They appear in Photoshop, Blender, After Effects, Cinema 4D, Virtual Production, Game Design, fabrication and communication projects.

| Skill ID | Skill | Stage | Evidence standard |
|---|---|---|---|
| GD-CON-01 | Contrast | Bootcamp | Uses value, colour, size, shape or type contrast to make important information visibly distinct. |
| GD-HIE-01 | Visual hierarchy | Bootcamp | Establishes a deliberate first, second and third visual priority appropriate to the brief. |
| GD-ALN-01 | Alignment | Bootcamp | Uses shared edges, guides, grids or spatial relationships instead of arbitrary placement. |
| GD-PRO-01 | Proximity / grouping | Bootcamp | Groups related information and separates unrelated information to improve comprehension. |
| GD-REP-01 | Repetition / consistency | Bootcamp | Repeats purposeful visual rules to create unity without mechanical duplication. |
| GD-COL-01 | Colour relationships and readability | Bootcamp | Chooses colour roles that support emphasis, readability and intended mood. |
| GD-TYP-01 | Typography as communication | Bootcamp | Selects and organizes type to support voice, hierarchy, readability and audience. |
| GD-AUD-01 | Audience and purpose | Guided Projects | Explains how visual decisions support the intended audience, purpose and desired response. |
| GD-MET-01 | Visual metaphor | Guided Projects | Uses an image/relationship symbolically and can explain how it reinforces the message. |
| GD-BRD-01 | Brand consistency | Client/Branding | Applies a coherent voice, palette, type and visual system across a client brief. |
| GD-DEM-01 | Demographic fit | Client/Branding | Uses evidence about a target demographic to justify communication choices without relying on stereotypes. |
| GD-CTA-01 | Message / call to action | Client/Branding | Makes the intended message or action clear and appropriately prominent. |
| GD-CRIT-01 | Critique and revision | All stages | Identifies a meaningful weakness, tests a revision and explains why the change improves communication or technical quality. |

## Learning progression
Bootcamp introduces principles explicitly. Technique applications revisit them briefly. Guided ads connect them to professional examples. Client/branding projects require students to justify choices against a fictional brief and target demographic. Campaign work requires transfer across formats.
