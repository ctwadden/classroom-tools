# DESIGN FOUNDATIONS SKILLS — Cross-Software Registry

| Skill ID | Skill | Evidence standard |
|---|---|---|
| GD-CON-01 | Contrast | Uses value, colour, size, shape or type contrast to make important information distinct. |
| GD-HIE-01 | Visual hierarchy | Establishes deliberate first, second and third visual priority. |
| GD-ALN-01 | Alignment | Uses shared edges, guides, grids or spatial relationships instead of arbitrary placement. |
| GD-PRO-01 | Proximity / grouping | Groups related information and separates unrelated information. |
| GD-REP-01 | Repetition / consistency | Repeats purposeful visual rules to create unity. |
| GD-COL-01 | Colour relationships and readability | Chooses colour roles supporting emphasis, readability and mood. |
| GD-TYP-01 | Typography as communication | Selects and organizes type to support voice, hierarchy, readability and audience. |
| GD-AUD-01 | Audience and purpose | Explains how visual decisions support audience, purpose and desired response. |
| GD-MET-01 | Visual metaphor | Uses imagery symbolically and explains how it reinforces the message. |
| GD-BRD-01 | Brand consistency | Applies coherent voice, palette, type and visual system across a brief. |
| GD-DEM-01 | Demographic fit | Uses evidence about a target demographic without stereotypes. |
| GD-CTA-01 | Message / call to action | Makes the intended message or action clear and appropriately prominent. |
| GD-CRIT-01 | Critique and revision | Identifies a weakness, tests a revision and explains why it improves the result. |

Bootcamp teaches principles explicitly. Guided projects connect them to professional examples. Client/branding work requires demographic/client justification and campaign transfer.
