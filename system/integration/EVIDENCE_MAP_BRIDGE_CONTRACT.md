# OUTCOME EVIDENCE MAP / EVIDENCE STUDIO BRIDGE CONTRACT

The systems are aligned by design but are not yet a live API integration.

- Outcome Evidence Map: semester/module/sprint/project planning and evidence profile.
- Teach OS / Truck Standard resources: learning sequence and student resources.
- Evidence Studio: rubrics, question branches, observation look-fors, conferences, review queue and teacher-confirmed judgement.

Preserve canonical IDs: course, project, skill, outcome, evidence opportunity and PowerSchool assignment.

Minimum planned evidence fields:
course_id, module_id, project_id, project_title, assignment_id, evidence_id, evidence_type, checkpoint_title, skill_ids, outcome_codes, independence_target, purpose, count_in_achievement, teacher_verified_required, powerschool_publish, gradebook_display_name, resource_url.

Planned evidence is not student evidence. Actual evidence later adds student_id, attempt, date, evidence_note, level, independence and teacher_verified.

Default reporting: internal Obs/Con/Pro evidence stays in the evidence system; one summative project assignment per course configuration publishes to PowerSchool.
