# Learning Studio Workbook Standard
Version: 1.0
Status: CANONICAL

## Universal spine
A substantial Learning Studio resource should support:

1. Authentic Context
2. Brief / Essential Question
3. Outcomes
4. Skills / Concepts
5. Prerequisites / Builds On
6. Learning Pathway
7. Exact Instruction
8. WHY / CHECK / FIX or domain equivalent
9. Knowledge / Retrieval
10. Evidence Opportunities
11. Reflection
12. Independent Transfer
13. Defence / Explanation
14. Assistant Coach Boundaries
15. Delivery / Video Metadata
16. QA / Status

Use two sizes:
- Learning Studio Lesson
- Learning Studio Project / Sprint

Do not make every daily lesson a giant project.

## Assessment
**KNOW → DO → EXPLAIN → APPLY → REFLECT → TRANSFER**

Knowledge supports judgement but does not automatically establish mastery.

Achievement evidence:
- Observation
- Conversation
- Product

Transfer requires changed conditions and teacher verification where used as Extending evidence.

## Support
Assistant Coach principle:
**Reduce friction, not thinking.**

Support bands:
- Guided
- Supported
- Independent
- Transfer

Achievement bands:
- Beginning
- Developing
- Secure
- Extending

Never merge these dimensions.

## Digital Society profile

**Technology → How It Works → Real Case + Evidence → Stakeholders → 3Cs → Impact → Implication → Counter-Perspective → Trade-Off → Qualified Judgement**
