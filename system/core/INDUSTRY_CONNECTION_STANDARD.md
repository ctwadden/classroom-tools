# INDUSTRY CONNECTION STANDARD

Every major software project begins by connecting the classroom task to professional practice.

## Required top-of-project block
1. **Industry Connection** — one verified real-world campaign, production, game, film, motion piece or professional workflow.
2. **Client / Audience Problem** — who is being influenced, informed or served?
3. **Design Lens** — 3-6 principles students should notice before touching the software.
4. **Professional Question** — what should the viewer notice, feel, understand or do?
5. **Copyright-safe reference** — link to the original/case study; do not automatically redistribute copyrighted campaign imagery on public GitHub.

## Truck Ad example
The 2008 Ford F-150 campaign discussed by Animation World Network described a collaboration between JWT/Team Detroit and Offspring using live-action truck footage, rugged natural environments, graphic type and visual puns.

This is a useful professional parallel for the Truck Ad because students can study how image, type, texture, setting and metaphor reinforce a toughness message.

The classroom project is not a replica or endorsement of Ford advertising. It uses the professional example to make design reasoning visible.
