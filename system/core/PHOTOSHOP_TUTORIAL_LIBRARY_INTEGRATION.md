# PHOTOSHOP TUTORIAL LIBRARY INTEGRATION

## Canonical library
The existing:
- `Photoshop_Tutorial_Library.xlsx`
- `Photoshop_Tutorial_Library.html`

remain the tutorial discovery and source-audit library.

## Relationship to Truck Standard
The library is an intake queue, not a verification stamp.

A library tutorial can be:
- discovered
- reviewed
- source verified
- asset audited
- selected for conversion
- converted to Truck Standard
- preflighted
- VERIFIED

## Basecamp
B01-B19 remain useful prerequisite/refresher sources.

Truck Standard projects should reference canonical skill IDs (for example PS-LAY-01 or PS-SMO-01), and the skill registry may point those IDs to the matching Basecamp source.

## New tutorial intake rule
When a new Photoshop tutorial is found in any chat:

1. Add/update it in the Photoshop Tutorial Library.
2. Give it/retain a stable library ID.
3. Identify prerequisite and target canonical skills.
4. Mark source/provenance/compatibility/asset rights.
5. If chosen for classroom use, create a project manifest.
6. Run the Truck Standard production + assessment workflow.
7. Add its project assessment spec to the GitHub registry.
8. Generate Google forms from the shared Technology Evidence System.

This keeps the "tutorial list chat" and the "Truck Standard chat" synchronized through files rather than conversation memory.
