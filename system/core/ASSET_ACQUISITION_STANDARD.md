# ASSET ACQUISITION STANDARD

## Purpose
Every instructional project must use assets that are technically usable, visually compatible, and legally traceable before the tutorial manuscript is written.

## The four asset routes
1. **Creator / teacher-owned originals** — preferred when clean files and redistribution rights are clear.
2. **Free stock** — Pexels, Unsplash, Wikimedia Commons, CC0 and similar sources. Record creator, source URL, licence and download date. Check depicted trademarks, recognizable people and other third-party rights.
3. **AI-generated instructional assets** — preferred when a specific camera angle, lighting setup, unbranded product or matching asset set cannot be found efficiently. Save the prompt, generation date/tool and intended classroom use.
4. **Legacy reference** — old/watermarked/unclear-rights material can remain as a teacher-only benchmark but is never the public student starter file.

## Acceptance Gate
A major source image does not enter a Truck Standard package until it passes:
- useful resolution (normally 2000px+ useful long edge for the hero subject)
- useful camera angle / perspective
- compatible or matchable lighting
- enough detail for selection/masking/warping
- no unavoidable watermark
- recorded licence/provenance
- credible performance in the actual prototype composite

## Storage
**Google Drive is the canonical source library.** Store originals, licence/source records, AI prompts/generation records, prepared classroom assets, checkpoints and exemplars.

**GitHub is the delivery layer.** Only approved classroom files or download links go into the public repository.

## Project rule
Do not write detailed student instructions around an asset that has not passed the acceptance gate.
