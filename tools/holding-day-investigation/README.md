# Inside the Feed — Investigation Studio

Student-ready 60-minute holding-day investigation for:

- Multimedia 12
- Communications Technology 11
- IB Digital Society SL

This cross-course version lives in the shared `classroom-tools` repository so course sites can link to one maintained copy.

## Student flow

1. Draw one guided mission.
2. Use the assigned video and starting source.
3. Build a five-stage mechanism or creative-pipeline map.
4. Complete the eight-part Field Report.
5. Defend one conclusion and revise one part.

## Teacher checks

- Confirm YouTube and external source sites are accessible on the school network.
- Decide whether the task is **No AI**, **AI for support**, or **AI as part of the investigation**.
- Do not use an AI-detector score as proof of misconduct. Compare source trail, working decisions, explanation and revision instead.
- Student responses saved in the browser are only a local draft; students should move final work into the required submission workflow.
