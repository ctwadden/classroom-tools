# Classroom Tools

A shared library of student-facing classroom web tools used across courses.

## Structure

- `tools/` — self-contained classroom activities and mini-apps
- each tool keeps its own `index.html`, supporting assets, templates, and documentation

## Current tools

- **Holding Day Investigation Studio** — cross-course investigation activity for Multimedia 12, Communications Technology 11, and IB Digital Society SL

This repository is intended to keep reusable classroom tools in one place so course sites can link to the same maintained version instead of duplicating files.
